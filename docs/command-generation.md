# 04：生成当前网络的删除命令

04 读取活动 IPv4 路由和网卡，**只输出文本，不执行 `route.exe delete`**。命令包含目标前缀、网关与接口编号，避免只按目标地址宽泛删除。

生成条件必须同时满足：

- 前缀精确为 `198.18.0.0/24`。
- 接口编号为正整数，且能对应到 `HardwareInterface=true`、`Virtual` 不为 true 的网卡。
- 下一跳是可解析的 IPv4 地址，不是 `0.0.0.0` 或回环地址。

这套条件只筛选候选路由，不证明该路由一定有害。使用者需要确认本次故障与 Fake-IP 路由冲突一致。`198.18.0.0/30` 直连路由、TUN 等虚拟接口路由不生成删除命令。

匹配后，在管理员终端执行结果文件中的命令；换网络或路由改变后重新生成。输出固定在 `output/commands/route-delete-command.txt`，每次更新，包括无匹配或查询失败时，避免把旧网关命令当作当前结果。查询失败不等于路由不存在。

如果运行着 02，推荐先 03 保存故障现场，再手动恢复。停止某个相关服务并不保证清除它此前已创建的路由。工具不负责停用服务，也不判断哪项软件应被卸载。
