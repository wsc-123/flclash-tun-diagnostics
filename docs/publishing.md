# 本仓库的公开范围

本仓库仅包含启动器、PowerShell 实现、测试、说明和人工整理的脱敏案例。未包含原始 ETL、诊断报告、完整进程/服务快照、生成的个人网络删除命令或历史备份。

发布版移除了个人入口域名、入口 IP 和旧 DNS 默认值，改为可选参数；安装路径相对工具根目录计算。案例中的网关使用 `192.0.2.1` 文档示例地址，进程和接口使用代号，时间使用相对值。Fake-IP 地址段、事件 ID 和组件名称为解释机制所必需，予以保留。

`output` 的运行结果、原始 ETL、备份、临时测试文件和本地发布记录由 `.gitignore` 排除。忽略规则不是内容脱敏器：不要强制添加个人日志。需要分享新故障时，请单独摘录必要字段，删除用户名、机器名、MAC、网络地址、访问域名、节点/订阅信息及无关进程清单；保留原始版本在本地，避免丢失证据。

脚本内置的凭据遮盖仅处理已知密钥及部分常见 URL 凭据格式。它不保证报告匿名化，也不会自动处理二进制 ETL。
